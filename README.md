# Phantom Gomoku（幻格五子棋）

> 🎓 **这是我的第一个 Vibe Coding 项目** —— 通过与 AI 结对编程，从零开始构建的一款融合塔罗牌主题的五子棋游戏。整个过程以自然语言描述需求，AI 辅助完成架构设计、编码实现与迭代优化。

基于 **C++17 + SFML 3** 的五子棋游戏，独创 **22 张塔罗大阿尔卡纳卡牌事件系统**，支持人机对战、本地双人与局域网联机三种模式。

## 玩法说明

### 基本规则

- 在 **15×15** 的棋盘上，黑白双方轮流落子
- 先在横、竖、斜任一方向上连成**五子**者获胜
- 若棋盘下满仍无人五连，则为**平局**

### 幻格模式（障碍物玩法）

在经典五子棋基础上，棋盘上会随机出现**障碍物**（最多 8 个），棋子不能落在障碍格上。障碍物的存在打破了传统的定式思维，更考验临场应变。

每过若干回合，旧的障碍物会消失并在新位置生成。

## 主菜单与场景导航

游戏启动后进入**主菜单**，共 6 个入口：

| 按钮 | 功能 |
|------|------|
| **经典模式 · 人机对战** | 15×15 标准棋盘，与 AI 对弈 |
| **幻格模式 · 人机对战** | 含障碍物的棋盘，与 AI 对弈 |
| **经典模式 · 双人对战** | 同屏双人轮流落子 |
| **联机对战** | 创建或加入局域网房间 |
| **规则说明** | 3 页游戏说明（含卡牌系统介绍） |
| **退出游戏** | 关闭程序 |

点击任意模式后会进入**难度选择**（人机模式下）或直接开始对局。

## 游戏内操作

### 鼠标操作

| 操作 | 方式 |
|------|------|
| 落子 | 左键点击棋盘交叉点 |

- **切换对战方式** — 人机 ↔ 双人对战

## 棋盘模式

| 模式 | 特点 |
|------|------|
| **经典棋盘** | 空棋盘，纯五子棋规则 |
| **幻格棋盘** | 棋盘上随机分布 0~8 个障碍物，每几回合自动刷新位置 |

在 Hard 难度下，障碍物会**动态变化**：AI 会主动清除对自己不利的障碍、在关键位置生成新障碍。

---

## AI 难度

| 难度 | 说明 |
|------|------|
| **Easy（简单）** | 随机选择可落子位置，适合新手入门 |
| **Medium（中等）** | 基于评分函数评估每个位置的进攻/防守价值，选取最优落子点 |
| **Hard（困难）** | 在 Medium 基础上增加障碍物智能管理 —— 清除威胁最大的障碍物、在对手关键路径上生成障碍 |

AI 对局中，对手角色精灵会根据状态切换动画（Idle / Think / Win / Lose），并伴有对话气泡。

## 塔罗牌事件系统

这是本作最具特色的玩法。每当棋盘上总棋子数达到阈值（10 → 18 → 26 → 34 → …），触发**卡牌事件**：

1. 画面变暗，信使角色出现
2. 从 22 张大阿尔卡纳中**随机抽取 3 张**展示
3. 玩家（联机时由命运之轮随机决定选择权）**选择 1 张**
4. 卡牌效果立即作用于棋盘

## 局域网联机

### 创建房间（主机）

1. 主菜单 → **联机对战** → **创建房间**
2. 配置房间参数：
   - 棋盘模式（经典/幻格）
   - 悔棋次数（0~9）
   - 回合时间限制（秒）
   - 障碍物是否动态变化
   - 可选棋盘地图
3. 等待客机连接（显示本机 IP 和端口号 `12345`）

### 加入房间（客机）

1. 主菜单 → **联机对战** → **加入房间**
2. 输入主机 IP 地址
3. 连接成功后等待主机开始

### 联机特性

- TCP 可靠传输，二进制协议
- 命运之轮同步：服务器决定谁有权选择卡牌
- 卡牌 RNG 种子由服务器统一下发，确保双方效果一致
- 支持在线悔棋、投降、重新开始
- 断线自动检测

## 从源码构建

### 环境要求

| 组件 | 版本/说明 |
|------|-----------|
| C++ 编译器 | GCC 14+（MinGW-w64）或 MSVC 2022+ |
| CMake | ≥ 3.20 |
| SFML | **3.0.0**（2.x 不兼容） |
| Ninja | 推荐，避免 MinGW Make 中文路径问题 |
| 操作系统 | Windows 10/11 |

### 安装 SFML 3

1. 从 [SFML GitHub Releases](https://github.com/SFML/SFML/releases/tag/3.0.0) 下载 `SFML-3.0.0-windows-gcc-14.2.0-mingw.zip`
2. 解压到任意目录，记下路径（如 `D:/SFML-3.0.0`）

### 修改 CMake 预设

打开 [CMakePresets.json](CMakePresets.json)，将 `SFML_DIR` 改为你的 SFML 安装路径：

```json
"SFML_DIR": "你的路径/SFML-3.0.0/lib/cmake/SFML"
```

### 编译

```bash
# 配置（生成 Ninja 构建文件）
cmake --preset default

# 编译（6 个源文件 → phantom_gomoku.exe）
cmake --build --preset default
```

产物在 `build/phantom_gomoku.exe`，运行前确保 `assets/` 文件夹在同目录下。

### VS Code 集成

项目已包含 `.vscode/` 配置，使用 `Ctrl+Shift+B` 即可调用 CMake 预设构建。

## 项目架构

```
Phantom-Gomoku/
├── CMakeLists.txt              # CMake 构建脚本（C++17 + SFML 3）
├── CMakePresets.json           # Ninja / MinGW 双预设
├── .gitignore
├── .vscode/                    # VS Code 构建/调试配置
├── assets/                     # 游戏素材
│   ├── *.png                   # UI 按钮、棋盘纹理、角色精灵
│   ├── *.mp3 / *.wav           # BGM、音效（含卡牌事件音乐）
│   └── fusion-pixel-*.ttf      # 融合像素字体（简体中文）
└── src/                        # 源码
    ├── main.cpp                # 入口：创建 Game 并调用 run()
    ├── Game.hpp                # Game 类声明（~927 行，含所有枚举与结构体）
    ├── Game.cpp                # 核心逻辑与渲染（~13,800 行）
    ├── Board.hpp               # Board 类声明：棋盘数据模型
    ├── Board.cpp               # 棋盘实现：落子、胜负判定、障碍物管理
    ├── NetworkServer.hpp       # TCP 服务器：监听、收发、协议解析
    ├── NetworkServer.cpp       # 服务器实现
    ├── NetworkClient.hpp       # TCP 客户端：连接、收发、房间配置
    ├── NetworkClient.cpp       # 客户端实现
    └── NetworkCommon.hpp       # 网络协议公共定义（NetMove、RoomConfig）
```

### 代码规模

| 文件 | 行数 | 职责 |
| ---- | ---- | ---- |
| `Game.cpp` | ~13,800 | 场景管理、渲染、AI、卡牌事件、动画、粒子、音效 |
| `Game.hpp` | ~927 | 所有枚举、结构体、方法声明 |
| `Board.cpp` | ~976 | 棋盘状态、落子判定、障碍物逻辑 |
| `Board.hpp` | ~114 | Board 类接口 |
| `NetworkServer.cpp` | ~199 | TCP 监听与数据包收发 |
